## 一些有关ssh的使用记录

### 通过scp复制文件

上传本地文件到远程服务器：
scp /path/to/local/file.txt user@remote_host:/path/to/remote/directory/
这条命令会把本地的file.txt复制到远程主机的指定目录下。

从远程服务器下载文件到本地：
scp user@remote_host:/path/to/remote/file.txt /path/to/local/directory/

复制整个目录：记得加上 -r 参数（递归）。
scp -r /path/to/local/folder user@remote_host:/path/to/remote/directory/

指定端口：如果SSH端口不是默认的22，使用 -P（大写）参数。
scp -P 2222 file.txt user@remote_host:/remote/dir/

注意：上述远程目录或者文件如果不是root用户登录，则最好权限也不是root，否则会提示权限不够。

### 通过sftp操作文件

sftp：交互式管理，像在FTP中操作
当你不确定远程目录结构，或需要执行多种文件操作时，sftp非常方便。

连接到远程服务器：

sftp user@remote_host
连接成功后，你会进入一个sftp> 交互式命令行，可以使用类似FTP的命令：

ls, cd：列出、切换远程目录。
lls, lcd：列出、切换本地目录。
put local_file：上传文件到远程当前目录。
get remote_file：下载文件到本地当前目录。
mkdir, rm：在远程创建、删除目录。
exit 或 bye：退出sftp会话。

### 目录名字需要注意的地方
一个小细节：关于“/”：源目录路径末尾的斜杠很重要。
folder/ 表示复制目录内的内容到目标目录。
folder（无斜杠）表示复制目录本身到目标目录。

### 重装系统添加一个用户abc

创建家目录, -G 指定附加组(sudo), -s 指定默认shell
sudo useradd -m -G sudo -s /bin/bash abc

执行后，需要单独为该用户设置密码：
sudo passwd abc
